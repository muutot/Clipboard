# 自定义 CSS

入口：**设置 → 外观 → 自定义 CSS**。默认关闭、代码为空。
编辑后点击“保存并应用”，即可更新当前窗口和其他已打开的窗口。
关闭开关会保留代码；“撤销编辑”恢复已保存内容，“清空编辑器”只修改草稿。

```css
:root {
  --accent: #7c6cf2;
  --selection-color: #7c6cf2;
}

.clip-card {
  border-radius: 10px;
}
```

如果样式遮住了界面，在应用窗口获得焦点时按 **Ctrl+Shift+F12**；
macOS 使用 **Cmd+Shift+F12**。这会关闭自定义 CSS 并保存关闭状态，代码不会删除。
该组合键仅在自定义 CSS 开启时被恢复逻辑接管。

## 优先级与支持范围

- 浏览器解析样式；普通样式声明自动提升为 `!important`，放入预先声明的首个层
  `clipboard-custom-overrides`。它优先于应用内置样式、后加载的组件样式和普通行内样式，
  因此主题面板写入的行内变量也不会把用户覆盖冲掉。
- 支持 CSS 选择器、自定义变量、嵌套样式、条件规则及动画。
  动画关键帧和字体描述符不添加 `!important`，遵循其原生语义。
- 用户规则之间仍遵循 CSS 层叠规则。浏览器用户样式、原生系统控件、行内
  `!important`、正在运行的 CSS transition 等有自己的层叠或绘制规则，
  本功能不改变浏览器或操作系统的这些规则。
- 不支持 `@import`；解析在构造样式表或无浏览上下文的文档中完成，
  不为解析草稿加载资源。最终规则通过 `textContent` 写入，不能注入 HTML。
  Tauri 原有 CSP 保持不变，外部网络样式、字体和图片不会因此获得权限。
- 浏览器会忽略无效声明；完全没有有效规则的非空草稿不能保存。最多 65,536
  个 UTF-16 单元，与文本框长度和 Rust 保存校验一致；超限保存拒绝且保留旧配置。
- `general.customCss` 和 `general.customCssEnabled` 使用已有配置补丁、保存和
  跨窗口事件链路。草稿不会逐键应用；保存失败会显示错误并保留内容供重试。
  其他窗口更新设置时，不覆盖当前未保存草稿。
