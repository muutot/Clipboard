# 默认策略与隐私边界

## 首版默认值

- 主窗口唤起快捷键：`Alt+V`，保存在 `conf/keyboard.json`
- 普通历史记录数量上限：10,000 条
- 普通历史记录保留期：30 天
- 收藏记录不受数量上限和保留期自动清理影响
- 开机自启动默认关闭
- 网络访问默认关闭
- 辅助功能等高权限仅在用户启用快速粘贴等相关能力时按需申请

数量和时间采用双上限：达到任一条件时即可进入清理候选。真正执行清理时必须再次排除收藏项，并同步清理对应的图片、文件、OCR 数据和搜索索引文档。

## 本地优先原则

- 剪贴板内容、图片、文件副本、OCR 结果和搜索索引默认只保存在本机
- 默认不上传任何剪贴板内容，不启用遥测，不发送使用统计
- Tantivy 索引是可丢弃的派生数据；SQLite 与文件系统中的本地资源才是数据源
- 将来若加入同步、备份或在线能力，必须由用户显式开启，并分别说明上传范围

## 敏感内容

默认不记录已知密码管理器来源。初始忽略列表与运行时识别名单共用同一份常量（`privacy::PASSWORD_MANAGER_APPS`），当前包含：1Password、Bitwarden、Dashlane、iCloud Keychain、KeePass、KeePassXC、LastPass、NordPass、Windows Credential Manager。来源应用识别尚不可用的平台不能假装已经完成敏感来源拦截，应允许用户暂停记录，并在平台能力接入后再执行忽略列表。

敏感内容处理遵循以下顺序：

1. 来源应用位于忽略列表时，不创建历史记录，也不写文件、OCR 队列或搜索索引。
2. 用户暂停记录时，不采集新内容。
3. 已保存内容始终可以由用户删除；正式发布前开发版本允许删库重建。
4. 默认不尝试通过内容模式猜测并上传、分类或分析密码等敏感文本。

## 权限范围

- 剪贴板读取仅用于用户开启的历史记录功能
- 全局快捷键仅注册用户配置的组合
- macOS 辅助功能权限只在启用快速粘贴时申请
- 文件系统访问限制在配置目录、数据目录和用户明确选择的文件位置（webview 的 asset 协议 scope 仅含应用自身目录与受管 storage 根目录——跟随用户配置的数据目录，运行时通过 `asset_protocol_scope().allow_directory` 授权；无全盘通配）
- 网络权限默认关闭；更新、同步和备份功能未来分别申请并提供独立开关

这些值保存在 `conf/conf.json`，快捷键绑定例外地保存在 `conf/keyboard.json`。后续设置界面修改默认值时，应继续保持两个配置文件的职责边界。
