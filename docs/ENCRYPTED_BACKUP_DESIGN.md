# 加密可携备份设计

状态：设计已核对当前备份实现，尚未实现或发布加密格式。本文件不能作为功能已可用的证据。

## 保护范围

目标是保护脱离设备的备份文件：记录正文、标题、标签、来源、文件名、资源内容及原始路径。攻击者可以取得和修改备份，但没有口令。文件总大小、格式版本及分块长度会泄露；不承诺隐藏备份存在或大小。

不保护已解锁进程的内存、操作系统剪贴板、本地 SQLite/WAL、Tantivy、现有资源目录、交换文件或用户明确导出的未加密文件。S3 密码和平台密钥存储不能自动保护这些本地内容。

口令仅由用户输入，不复用同步口令，不持久化、不进入日志、操作事件或错误文本。UI 使用密码输入，不提供默认口令；加密导出必须确认口令，恢复使用同一用户口令。丢失口令无法恢复，没有后门或账户重置。用户仍可显式选择旧版未加密备份。

## 现有实现约束

`export/backup.rs::create_with_progress` 将 records.jsonl 写入私有临时目录，再生成 ZIP；`load` 又将完整 ZIP 复制到私有临时 archive.zip。私有权限减少跨用户读取，无法等同于加密。禁止用“创建明文 ZIP，再套加密”的方式宣称没有明文临时备份。

现有约束继续保留：100,000 条记录、单条 32 MiB、记录总计 512 MiB、单资源 2 GiB、资源总计 16 GiB、元数据类型验证、受控资源名、预览指纹、恢复事务及维护锁。恢复不携带配置、凭据、回收站或派生预览。

## 拟采用的格式

加密格式独立于现有 ZIP v1；文件扩展名继续使用 .clipbackup，按固定魔数识别。未知版本直接拒绝，不能退回文本或 ZIP 猜测。以下参数须在实现与格式测试后冻结，当前不是互操作规范。

- 头部：8 字节魔数、固定版本、32 字节随机盐、8 字节随机 nonce 前缀。安全随机生成失败时中止。
- KDF：PBKDF2-HMAC-SHA256，固定 600,000 次，派生 32 字节密钥，增加备份专属域分离。格式不接受攻击者指定的任意工作因子。不得复用依赖同步命名空间的 SessionKey。
- 加密：AES-256-GCM，16 字节认证标签；每块 nonce 为前缀加 32 位块序号，序号不得重用或溢出。
- 每块保留明文长度用于有界读取；块最大 1 MiB。AAD 绑定完整头部、序号与长度。解析前先校验长度上限，再分配缓冲区，认证后才解释载荷。
- 块内载荷区分记录、资源开始、资源数据、资源结束与最终提交。类型和名称随载荷加密；资源采用内部 ID，不能携带可用于直接落盘的绝对或相对源路径。
- 每个资源结束帧认证实际字节数及 SHA-256；最终帧认证记录数、资源数和累计字节数。必须有且只有一个最终帧，随后必须 EOF；拒绝截断、尾部追加、乱序、重复、漏块及拼接。
- 空备份仍有经过认证的最终帧，不能把空文件或只有头部的文件当作成功。

新格式直接流式导出资源与记录，不使用明文 ZIP 或 records.jsonl 临时文件。目标写入同目录密文 staging，只有完整最终帧、flush 和原子发布成功后才替换已有目的地。取消、错误、磁盘满保持已有目的地内容。

## 恢复和预览

输入先复制到带当前用户权限的私有密文 scratch 并计算指纹；不能在攻击者可同时改写的原文件上进行验证后恢复。任何认证错误统一反馈“口令错误或备份损坏”，不包含口令、解密内容或源路径。

预览先完整验证认证、最终帧和现有数据契约，仅读取统计，绝不写入现有数据库或资源目录。恢复重新验证同一备份指纹；口令和指纹均须匹配。改变口令、选择路径或导出模式时清空过期预览，不缓存已解密正文。

恢复不得在 OS 临时目录生成完整明文 archive/records spool。需要重复扫描时扫描密文 scratch；块内存使用后清除。最终要恢复的明文资源只能在全部认证成功后进入私有托管 staging，并继续使用现有授权、内容校验、原子发布和数据库事务。这段资源发布 staging 是本地明文存储边界的一部分，需要在 UI 隐私说明中明确，不能宣称本地数据静态加密。

取消在 KDF 前后、分块读写、验证及数据库提交前检查。事务开始后沿用当前恢复取消/回滚契约。密文 scratch 和未发布资源在失败或取消后回收；不得为清理而删除无法确认引用的既有资源。崩溃残留纳入有所有权标识的保守启动回收，不扫描或删除任意临时目录。

## UI 与契约

复用 BackupPanel 的共享设置原语与 BackgroundOperationStatus。加密是显式导出选择；旧版 ZIP 导出保留。新增 command 参数使用可选 password，空口令不能静默产生未加密文件；旧调用不带参数时保留 v1 兼容。

预览/恢复按文件魔数决定是否需要口令，不能凭扩展名判断。不得记录敏感 invoke 参数；检查前端及后端错误日志路径。口令值在操作结束、取消或面板卸载时清除，恢复确认保留既有预览门禁。密码输入不读取后台配置，不建立新持久化设置。

英语提示语义：Encrypted backup protects this backup file only. Local history remains unencrypted. A lost password cannot be recovered. Restore errors must say Wrong password or damaged backup without exposing content.

## 实施与验收顺序

1. 独立有界分块编解码器：认证头部/顺序/长度/终止，密钥清除与取消测试。
2. 直接流式打包和密文 scratch 恢复：复用现有 metadata 与资源授权契约，禁止新增明文 archive/records spool。
3. IPC、服务、双语密码/确认流程：预览指纹和操作生命周期保持一致。
4. 真实临时数据库/文件测试：旧 ZIP 兼容、正确/错误口令、逐字段篡改、截断、追加、空备份、块边界、过量长度、取消、目的地保护和已有数据保护。
5. Windows 原生恢复和 UI 检查；macOS/Linux 仅在匹配环境验收。检查 scratch 及日志中不存在合成秘密正文。

## 分块原型证据

src-tauri/tests/encrypted_backup_codec.rs 为纯测试目标，不是应用模块。原型固定 49 字节头部、1 MiB 数据块、18 GiB 流总量及 1,000,000 帧上限；密文载荷类型为 data/final，最终帧认证字节数、帧数及 SHA-256。salt/nonce 使用可失败的 SysRng；派生密钥与载荷用 Zeroizing，AES-GCM 启用 zeroize feature。五项测试覆盖往返、空流、块边界、错误口令、篡改、截断、追加、乱序、重复、超量长度、随机化和写入失败后拒绝重试；对应 test target Clippy 通过。

解码返回的数据在 final/EOF 前是临时结果，禁止在此之前修改现有数据。原型尚未覆盖记录/资源帧、取消、真实文件、UI 或恢复事务；不能用于读取现有 .clipbackup，也不提供已发布格式兼容承诺。
