# Clipboard 用户指南

这份指南面向第一次使用 Clipboard 的用户，按「先会用、再用好」的顺序组织。前面的三分钟上手覆盖 80% 的日常场景，后面各节按需查阅。

首次启动时应用内也会播放一份精简版导引（设置 → 常规 → 新手导引 可随时重看）。

## 三分钟上手

Clipboard 在后台静默运行，你只需要记住一个循环：

```
复制任何内容 → Alt+C 唤起窗口 → 输入关键词 → ↑↓ 选择 → Enter 粘贴
```

1. **复制即记录**：复制文本、链接、图片、文件后，历史里立刻会出现对应卡片，无需任何额外操作。
2. **Alt+C 唤起 / 隐藏**：默认全局热键 `Alt+C`（可在 设置 → 快捷键 中修改）。窗口唤出后直接打字即可搜索，不需要先点搜索框。
3. **Enter 快速粘贴**：选中一条记录后按 `Enter`，内容会粘贴到唤起窗口之前的那个应用里。
4. **Esc 或 Alt+C 收起窗口**：应用继续在托盘后台记录，随时再唤出。

> 所有数据只保存在本机，应用不含任何遥测；只有你显式配置 S3 同步、检查更新或下载 OCR 模型时才会访问网络。

## 主界面导览

```
┌────────────────────────────────────────────┐
│ 搜索框（唤出即输入，支持建议与历史）          │
├────────────────────────────────────────────┤
│ 全部 文本 链接 图片 文件 收藏 回收站 │ 来源▾ 日期▾ 📌 ⚙ │
├────────────────────────────────────────────┤
│ 卡片列表（虚拟滚动，万级记录流畅）            │
│  标题 / 预览 / 来源·时间·操作按钮 / 标签      │
├────────────────────────────────────────────┤
│ 状态栏：结果摘要 · 运行时 · 当前唤起热键      │
└────────────────────────────────────────────┘
```

- **搜索框**：大字号无边框输入框，聚焦即可输入；`/` 或 `Ctrl+K` 可从任意位置聚焦。
- **工具栏**：分组标签（`Alt+1`~`Alt+7`）、来源应用过滤、日期过滤、固定窗口、设置入口、保存的搜索。
- **卡片**：单击选中，悬停显示操作按钮，右键呼出完整菜单，双击直接粘贴（可在设置中改为打开详情）。
- **状态栏**：显示当前结果数量、运行环境与唤起热键提示。

## 搜索

- **全文检索**：基于 Tantivy 引擎，中文按 N-gram 分词，多个关键词**无序 AND 匹配**（输入「报告 季度」能命中「季度……报告」）。
- **自然语言日期**：输入「昨天」「上周」「本月的第 3 天」等按时间过滤。
- **来源应用**：搜索词同时匹配记录来源的应用名，例如输入「chrome」。
- **搜索建议**：可切换 下拉面板 / Inline 行内提示 / 关闭；`Tab` 或 `→` 接受行内建议，`↑↓` 在建议列表移动。
- **组合过滤**：搜索与分组、来源、日期、标签过滤可以叠加；结果页底部继续滚动会加载更多。
- **保存的搜索**：工具栏的保存按钮可以把「关键词 + 全部过滤条件」存下来，之后一键还原。

## 对一条记录能做什么

| 操作                         | 方式                               |
| ---------------------------- | ---------------------------------- |
| 选中                         | 单击卡片，或 `↑` `↓`               |
| 复制                         | `Ctrl+C`（卡片按钮、右键菜单亦可） |
| 快速粘贴到上一个窗口         | `Enter` 或双击卡片                 |
| 纯文本 / 带格式 / 清洗并粘贴 | 卡片或详情面板操作菜单             |
| 收藏                         | `Ctrl+F`                           |
| 打标签                       | `Ctrl+T`，或右键卡片 / 标签页      |
| 查看详情                     | `Space` 或 `Ctrl+E`                |
| 编辑 / 另存为新条目          | 详情面板或卡片内联编辑             |
| 删除 / 恢复                  | `Ctrl+D`、回收站分组               |
| 导出 / 另存为（图片、文件）  | 卡片或详情面板菜单                 |
| `Ctrl+1`~`Ctrl+9`            | 快速复制列表前 9 条                |

**详情面板**（`Space` 打开）提供：

- **预览**：文本 / 代码（语法高亮）/ Markdown / 图片 / 文件内容预览，图片可全屏查看（缩放、拖拽）。
- **详情**：来源应用、时间、大小、类型、文件路径等元数据，以及识别出的特殊内容（邮箱、电话、颜色值、日期、货币、IP）一键操作。
- **标签**：添加、移除该条目的标签。
- **OCR**（仅图片条目）：查看识别文字、重新识别、复制选中区域文字。

**三种粘贴方式的区别**：

- **纯文本粘贴**：只写入 `text/plain`，目标应用按纯文本接收。
- **带格式粘贴**：保留 HTML/RTF 富文本格式（Word、浏览器编辑器等可保留样式）。
- **清洗并粘贴**：先去除首尾空白、合并连续空白、移除 URL 追踪参数，再粘贴。

## 默认快捷键

全局与应用内快捷键都可以在 **设置 → 快捷键** 中重新绑定，清空某个绑定即禁用该快捷键。

| 快捷键             | 作用                                                |
| ------------------ | --------------------------------------------------- |
| `Alt+C`            | 唤起 / 隐藏主窗口（全局）                           |
| `Alt+V`            | 打开 / 关闭悬浮窗（全局）                           |
| `/` 或 `Ctrl+K`    | 聚焦搜索框                                          |
| `↑` `↓`            | 移动选中                                            |
| `Alt+→` / `Alt+←`  | 下一个 / 上一个分组                                 |
| `Alt+1`~`Alt+7`    | 全部 / 文本 / 链接 / 图片 / 文件 / 收藏 / 回收站    |
| `Enter`            | 复制并粘贴到上一个窗口                              |
| `Ctrl+C`           | 复制选中条目                                        |
| `Ctrl+D`           | 删除选中条目（进回收站）                            |
| `Ctrl+F`           | 收藏 / 取消收藏                                     |
| `Ctrl+T`           | 给选中条目添加标签                                  |
| `Space` / `Ctrl+E` | 打开详情面板                                        |
| `Ctrl+S`           | 导出图片 / 文件条目                                 |
| `Ctrl+A`           | 全选当前列表                                        |
| `Backspace`        | 取消多选                                            |
| `Esc`              | 依次：关闭弹层 → 取消多选 → 清除标签筛选 → 隐藏窗口 |
| `Ctrl+1`~`Ctrl+9`  | 快速复制列表前 9 条                                 |

macOS 上 `Ctrl` 对应 `⌘`。

## 分组、筛选与标签

- **分组**：工具栏的 全部 / 文本 / 链接 / 图片 / 文件 / 收藏 / 回收站，对应 `Alt+1`~`Alt+7`。
- **筛选**：工具栏「来源」只显示某个应用复制的记录；「日期」限定 今天 / 昨天 / 近一周 / 近一月。
- **标签**：
  - 给任意条目打标签，标签参与全文搜索与列表筛选；
  - 点击卡片上的标签芯片即按该标签筛选，右键可重命名 / 改色；
  - 设置 → 标签 中批量管理：重命名、删除、着色；
  - 设置 → 标签规则 可按「正则 + 来源应用 + 内容类型」自动打标签，支持先预览再对历史生效。

## 收藏与回收站

- **收藏**：`Ctrl+F` 或卡片星标；在「收藏」分组集中查看，常用于常用链接、代码片段。
- **回收站**：删除默认进入回收站（设置 → 常规 → 回收站 可关闭，关闭后为直接删除）。回收站分组内可恢复或彻底删除。

## 图片与 OCR

- 复制的图片自动入库并生成缩略图，详情面板可全屏查看。
- **OCR**（设置 → OCR）：
  1. 选择引擎（默认 PP-OCRv6，可切换 Tesseract）与模型（tiny / small / medium）；
  2. 下载并安装模型（需联网一次，识别过程完全离线）；
  3. 之后复制的图片自动在后台识别，识别文字写入搜索索引——**搜图片里的文字和搜文本一样**；
  4. 详情面板 OCR 标签页可查看文字、重新识别、按区域复制。

## 悬浮窗

`Alt+V` 打开常驻小窗，适合「一边写东西一边翻历史」。悬浮窗条目的左键 / 中键 / 右键行为可以在 设置 → 悬浮窗 中分别配置为 复制、复制并粘贴、收藏、查看详情、删除或无操作；位置可记忆。

## 隐私与安全

- **本地优先**：记录保存在本机 SQLite 数据库，默认无任何网络上传。
- **暂停记录**：托盘菜单一键暂停 / 恢复，或在 设置 → 采集 → 敏感内容过滤 中切换。
- **忽略应用**：设置 → 采集 → 忽略的应用。常见密码管理器（1Password、Bitwarden、KeePass 等）会被自动识别并建议忽略。
- **敏感内容**：设置 → 采集 → 敏感内容过滤，用正则描述敏感内容，命中的复制不会被记录。
- **仅本地模式**：设置 → 采集 → 敏感内容过滤 中开启后，更新检查与模型下载等出站网络访问一律阻止。
- **同步加密**：如启用 S3 同步，数据以 AES-256-GCM 加密、密钥由你的口令派生后再上传（详见 `docs/SYNC_V1.md`）。

## 外观与窗口

- **主题**：暗色 / 亮色预设，20 个语义颜色变量可定制，可保存多套命名预设（设置 → 外观）。
- **字体**：5 个独立滑杆分别调节 主文字 / 次要文字 / 小文字 / 卡片标题 / 卡片预览（设置 → 外观 → 字体）。
- **窗口**：不透明度、毛玻璃（Windows 亚克力 / Mica，macOS 原生材质）、置顶、记住位置、开机自启、关闭到托盘、系统标题栏（设置 → 常规 → 窗口）。
- **布局**：卡片间距、内边距、圆角、最大文本行数、次要文字显隐、详情面板 覆盖切入 / 左右分栏（设置 → 外观 → 布局）。
- **自定义 CSS**：设置 → 外观 → 自定义 CSS，可覆盖任意内置样式；`Ctrl/Cmd+Shift+F12` 可临时禁用已保存的 CSS 以便排查。

## 导入、导出与备份

均在 **设置 → 存储 → 维护工具** 中：

- **导出**：支持 JSON / CSV / 纯文本，可按内容类型与日期范围筛选，可选包含收藏。
- **导入**：支持 JSON / CSV，以及 **PPaste 备份**恢复；超出条目上限时会提示调整限额。
- **资源备份**：可创建包含图片 / 文件资源的完整备份，并可预览、恢复。
- **维护**：数据库完整性检查与修复、搜索索引重建（同一页内）。
- **数据目录**：查看当前路径、迁移数据目录、自定义图片 / 文件资源根目录（设置 → 存储 → 存储路径）。

## 同步（可选）

设置 → 同步 中配置 S3 兼容存储（端点、桶、密钥），开启端到端加密并设置口令。同步支持自动（后台 worker 实时 / 懒加载）与手动「立即同步」两种模式，传输进度与取消在界面可见。未配置前不发生任何上传。

## CLI 与本地 API

- **CLI**：安装目录下的 `clipboard` 命令，支持 `list`、`search`、`copy`、`paste`、`delete`、`export`、`stats`，可与脚本、终端工作流集成。
- **本地 API**（面向本地自动化）：仅监听环回地址的 HTTP 接口，请求须携带 `Authorization: Bearer <token>`；token 首次启动时自动生成，保存在数据目录的 `conf/api.token`（服务启动后把绑定端口写入 `conf/api.port`），不对外网开放。

## 常见问题

**Q：为什么刚复制的密码没有出现？**
A：可能命中了敏感内容规则，或来源应用在忽略列表中（密码管理器通常会被自动建议忽略）。到 设置 → 采集 → 忽略的应用 与 设置 → 采集 → 敏感内容过滤 检查。

**Q：记录太多，会不会无限增长？**
A：默认上限 10,000 条 / 保留 30 天，可在 设置 → 存储 → 存储限制 调整。

**Q：搜索不到刚复制的内容？**
A：大批量导入或恢复后首次搜索需要先排空索引积压（约数百毫秒）；若始终搜不到，可在 设置 → 存储 → 维护工具 重建搜索索引。

**Q：换电脑怎么迁移？**
A：设置 → 存储 → 导入导出 全量导出 JSON（或创建资源备份），在新电脑导入；也可以配置 S3 同步。

**Q：Enter 粘贴到了错误的窗口？**
A：Enter 粘贴目标是「唤起主窗口之前的那个窗口」。如果先点了别的窗口再操作，请重新 `Alt+C` 唤出后立即按 `Enter`。

## 数据与隐私边界

- 数据库、索引、图片 / 文件资源、OCR 模型默认都存放在应用数据目录，可在 设置 → 存储 → 路径 查看与迁移。
- 应用不包含遥测与崩溃上报；日志仅写本地，级别可在 设置 → 常规 调整。
- 只有三个动作会访问网络：S3 同步、检查更新、下载 OCR 模型；「仅本地模式」下后两者被阻止。
