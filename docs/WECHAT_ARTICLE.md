## 正文开始

### 你是否有过这样的瞬间？

复制了一串链接，正要粘贴，Ctrl+C 却已被别的操作覆盖；截图里的文字想摘抄，只能对着图片手动敲键盘；昨天的订单号、上周的收货地址，想找回来却无处可寻……

剪贴板，这个我们每天使用上百次的功能，却总在最需要它的时刻「失忆」。

今天要介绍的，是一款开源的桌面剪贴板管理器 —— **Clipboard Desktop**。它用 Rust + Tauri 打造，本地优先、毫秒级全文搜索、离线 OCR，把你的剪贴板变成一台真正的「时光机」。

---

### 一、它是谁？

**Clipboard Desktop** 是一款高性能、跨平台、本地优先的剪贴板管理工具：

- 后台静默运行，持续记录剪贴板历史
- 全局热键一键唤起（默认 `Alt+V`）
- 支持全文搜索（含中文分词）、图片 OCR 文字识别
- 收藏、编辑、快速粘贴，一步到位

> 🔒 **隐私承诺**：所有数据存储在本地，不包含任何遥测或上传行为。OCR 完全离线运行，无需联网。

上手非常简单，只需记住一条路径：

```
Alt+V 唤起 → 键入关键词搜索 → ↑↓ 导航 → Enter 粘贴
```

---

### 二、核心特性一览

#### 📋 剪贴板记录：四类内容全覆盖

支持 **文本 / 链接 / 图片 / 文件** 四种内容类型，并内置智能识别：

- 识别邮箱、电话、颜色值、日期、货币、IP 等特殊内容
- 一键发邮件、拨号、打开链接、查看日期
- 内容哈希去重，避免重复记录
- 自触发抑制，防止程序写入自身内容被误捕获
- 历史上限 10,000 条 / 30 天保留（均可配置）

#### 🔍 全文搜索：10 万条记录，P95 小于 30ms

这是整个项目最「硬核」的部分：

- 基于 **Tantivy** 全文检索引擎，使用 N-gram 分词，中文搜索友好
- 多关键词无序 AND 匹配 + 相关性评分
- 自然语言日期搜索（「昨天」「上周」直接搜）
- 来源应用名称也参与搜索，记不清内容也能找到
- 搜索建议（下拉 / 内联提示），边输入边提示

#### 🖼️ 图片 OCR：截图里的字，也能搜

- PP-OCR 引擎，本地 ONNX 推理，**无需联网**
- 后台任务队列，识别结果增量写入搜索索引
- 模型选择 / 下载 / 安装 / 热重载
- 识别状态面板，随时查看 OCR 文本

#### 🎨 现代 UI：颜值与性能兼得

- Svelte 5 响应式界面，暗色主题
- 虚拟滚动，万级列表依然流畅
- 详情面板双模式：覆盖切入 / 左右分栏
- 图片全屏查看器，支持缩放拖拽
- 紧凑模式、自定义字体大小、自定义主题颜色（20 个 CSS 变量）
- 系统托盘、透明窗口、开机自启

#### ⚙️ 完善设置：想调什么都能调

- 双栏设置界面，分类导航 + 全局搜索
- 通用 / 外观 / 键盘 / 存储 / OCR / 主题 / 忽略应用 / 统计
- 性能监控面板：启动耗时、搜索延迟、内存占用一目了然

---

### 三、隐私与安全：数据不出本机

在剪贴板这种敏感场景，隐私是底线：

- **本地优先**：所有数据存储于本地 SQLite，无遥测
- **离线 OCR**：PP-OCR 引擎本地运行，无需联网
- **剪贴板暂停**：一键暂停/恢复记录
- **忽略应用**：自动识别密码管理器（1Password、Bitwarden、KeePass 等），避免捕获敏感内容
- **敏感内容**：可配置正则匹配模式

---

### 四、扩展能力：不止是一个 GUI

- **CLI 命令行**：`clipboard search` / `list` / `copy`，可写脚本自动化
- **本地 API**：HTTP 接口供外部脚本调用
- **导入导出**：JSON / CSV / 纯文本，支持类型和日期筛选
- **快捷键系统**：全局热键 + 应用内快捷键 + 双击修饰键（如 `Shift+Shift`）

---

### 五、技术栈：为什么快？

| 层级     | 技术                     | 说明                                     |
| :------- | :----------------------- | :--------------------------------------- |
| 桌面框架 | **Tauri 2**              | 轻量跨平台桌面壳，Rust 后端 + Web 前端   |
| 后端     | **Rust** (edition 2021)  | 剪贴板监听、存储、搜索、OCR、快捷键      |
| 数据库   | **SQLite**               | 版本化 Schema，仓储模式，自动备份恢复    |
| 搜索引擎 | **Tantivy 0.26**         | 全文检索，自定义 N-gram 分词（中文友好） |
| OCR      | **oar-ocr**（PP-OCR）    | 本地 ONNX 推理，支持 Tesseract 备选      |
| 前端     | **Svelte 5 + SvelteKit** | Runes 响应式语法，SPA 模式               |

Tauri 2 的轻量体积 + Rust 的原生性能 + Tantivy 的高效索引，三者叠加，才有了「10 万条历史秒搜」的底气。

### 六、快速上手

环境要求：Node.js >= 18、Rust 稳定版工具链，以及对应平台的 Tauri 2 系统依赖。

```sh
npm install          # 安装前端依赖
npm run tauri dev    # 启动桌面应用（热重载）
npm run tauri build  # 生产构建，生成安装包
```

支持 **Windows / macOS / Linux** 三平台。其中 Windows 全面使用原生 Win32 API（读写剪贴板、获取前台应用、提取应用图标），体验最完整。
